Mini Arcade 

Mini Arcade is a small handheld gaming device built using an ESP32-C3 and a 128×64 OLED display. It features three mini-games: a Tamagotchi-style virtual pet, Pong, and Dino Run.

Features

Tamagotchi: A little virtual pet with a blinking animation.

Pong: A classic Pong game with an AI-controlled opponent.

Dino Run: A simple jumping game where you avoid obstacles.

Two-button controls: Navigate the menu and play all three games.

OLED display: Shows the games, animations, and scores.

Hardware

Seeed Studio XIAO ESP32-C3

0.96-inch OLED display (128×64)

2 tactile push buttons

Connecting wires

Battery and enclosure

Software

Arduino IDE

C++

Adafruit GFX Library

Adafruit SSD1306 Library

Controls

Button

Function

A: Select games, jump, or move paddle up

B: Navigate menu or move paddle down

A + B

Hold to return to the main menu

How It Works

The ESP32-C3 runs the game code and controls the OLED display. The two buttons act as the main inputs, allowing the player to navigate the menu and interact with each game.
